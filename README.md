## Установка приложения

«Последний сигнал» можно установить как приложение на телефон или компьютер. Открой проект в браузере по HTTPS (или на `localhost`) и нажми **↓ Установить**. На iPhone/iPad открой меню **Поделиться → На экран Домой**. После первого запуска игра будет доступна офлайн, а сохранение останется на устройстве.
